The os Library & Directory Setup

To save pictures automatically for each student, we use Python's built-in os module!

# Folder Creation Code:
import os

name = input("Enter student's name: ")
folder = "faces/" + name #Use your own path

# Creates folder automatically if it doesn't exist yet!
os.makedirs(folder, exist_ok=True)
💡 Note: exist_ok=True prevents Python from throwing an error if the folder already exists!
